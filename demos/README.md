# 演示（待实现）

两周展示目标为 MS01：健康业务基线 → 实验坏发布与核验 → 真实告警和最小 webhook → 假设调查与证据 → 提案及规则／人工授权 → 受控回退 → 真实业务健康验证 → CLI、静态报告与完整证据包 → 环境复位。

当前没有可执行的 MS01 演示命令。I01 的环境与坏发布实验证据在 [env](../env/README.md) 和 [`faults/f01-bad-release/`](../faults/f01-bad-release/README.md)，它们是实验关卡，不含告警入口、模型调查、提案、授权和 CLI 报告，不能当作 MS01 展示链路。

具体步骤与断言以 [MVP 展示链路](../docs/mvp.md#4-两周展示链路)为准，推进顺序见[滚动迭代计划](../docs/iterations.md)。目前尚无可执行演示命令，不使用占位命令声称链路存在。

每阶段收录实际验证过的命令、代码／镜像／模型／策略版本、初始条件、操作、中间状态、结果、截图和复位方法。标明实验坏镜像、故障注入和真实运行边界，回放与 mock 单独标注。

调查不足、动作不适用、拒绝或恢复失败时保留真实状态；Kubernetes 自恢复、操作者修复与清理工具复位不能冒充 Agent 恢复。展示时只宣称证据支持的阶段，不把 MS01 称为完整 MVP。
