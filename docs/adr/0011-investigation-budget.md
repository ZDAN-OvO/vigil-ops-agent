# ADR-0011：调查预算按实测定值

- 状态：已采纳（2026-11-11，2026-11-14 由原决策记录合并）
- 相关：[ADR-0005](0005-langchain-single-agent-loop.md)、[ADR-0007](0007-skill-tool-subagent-runtime.md)、[配置](../../src/aiops/config.py)

## 背景

预算过小会截断正确的调查，过大会掩盖无效探索并抬高成本。早期临时默认值是工具 16 次、模型 8 次、墙钟 480 秒；在这个预算下，Redis 访问链路延迟场景有两轮被工具预算截断，另有两轮墙钟超限。

## 决定

- 调查预算：工具 28 次、模型 20 次、墙钟 600 秒；动作预算 450 秒。委派调查与主 Agent 共享同一份预算。
- 依据：2026-11-10 的 16 次真实运行中，成功运行的最大用量是工具 21 次、模型 7 次、墙钟 453 秒，各留约三成余量后取整，得到工具 28、模型 10、墙钟 600 秒。2026-11-11 的审批恢复真实运行表明，10 次模型调用不够覆盖调查、动作反馈和最终报告，于是把模型调用改为 20 次。
- 每次模型调用前按剩余时间限时；写操作前必须预留适配器的时间上界和一次反馈模型调用。

## 后果

- 修改数值前必须先重测并写明数据来源，不能因为某一次失败就调整，并且要经用户确认。
- 预算耗尽的运行按 `budget_exhausted` 或 `inconclusive` 如实记录，计入有效运行的分母。
