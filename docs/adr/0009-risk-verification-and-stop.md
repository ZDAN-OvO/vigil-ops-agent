# ADR-0009：规则风险分级、业务验证与异常停止

- 状态：已采纳（2026-11-14 由原决策记录合并）
- 相关：[ADR-0004](0004-controlled-resource-actions.md)、[全局架构](../../ARCHITECTURE.md)

## 背景

模型可以提出处置建议，但写操作是否执行、执行后算不算恢复，必须由可审查的规则判断。

## 决定

1. **风险分级以规则为主**：先判硬约束（命名空间白名单、动作注册表、证据有效性、并发冲突、资源身份与版本、适用性），再按动作类型、工作负载重要性、影响面、可补偿性、证据质量分级为自动、审批或禁止。不采信模型自报的置信度。权重与阈值尚未确定。
2. **恢复用真实业务请求判定**：在真实流量和固定窗口内，看错误率、延迟与平台状态。no data、遥测过期、仅 Pod Ready 都不算恢复。
3. **异常结果停止**：结果为无改善、恶化或未知时，停止同目标的后续自动动作，保存证据与人工待办，不重放写请求。
4. **补偿有边界**：只做单动作、限定字段的补偿，不承诺跨动作事务或业务数据回滚；自动补偿后置。

## 后果

- 当前唯一的自动允许规则是实验命名空间内可丢弃 Pod 的 `restart_pod`，其余动作需要人工审批，详见[操作手册](../../docs/USAGE.md#4-命令手册)。
- 审批绑定提案摘要、目标版本和有效期；过期或资源漂移须重新评估。
