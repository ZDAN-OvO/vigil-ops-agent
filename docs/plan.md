## 未完成状态与依据

- **规则形状的故障集偏向规则基线，第一轮已经证实**：2026-11-18 的对照里规则臂在四个
  场景上 12/12 诊断正确、零越界，耗时是 Agent 臂的百分之一量级；Pod 重建场景三臂同场时，
  规则 3/3 恢复、Agent 2/3、通用 Agent 0/3。这个结果支持"基线有效"，不支持"方法论有收益"，
  所以本轮不宣称收益。要证明收益，必须先扩一个规则覆盖不到的故障形状。
- **样本仍然是单机小样本**：同一模型、同一实验环境、单节点 k3d。门槛只约束"够不够比较"，
  不构成生产可用性或总体准确率的证据。
- **需要审批的动作不计恢复**：`f01` 的 `rollout_undo` 在 `vigil-shop` 需要人工审批，
  三条臂同等停在 `waiting_approval`。这些场景比较的是"提案是否正确"，恢复由批准方完成，
  不记任何一臂的恢复成功。
